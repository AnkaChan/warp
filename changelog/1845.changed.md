Make BVH ray and capsule queries stackless by precomputing per-node skip links, so directed queries walk the tree with two scalar cursors instead of a traversal stack and no longer claim the per-block shared-memory stack. Ray queries run 18-35% faster and capsule queries 11-33% faster on an L40; the links add 4 bytes per node (computed at build time, unchanged by refit) and query results are identical.
